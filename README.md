# PGA Tour Live Scoring Website

## 🏌️ Overview
This project is a **live scoring website** for PGA Tour golf tournaments. It features:
- **Real-time leaderboard updates**
- **Player profiles with a 72-hole score table**
- **Auto-refreshing scores**
- **Tournament resets at the start of each event**

## 🛠️ Installation & Setup
You can run the project locally by following these steps:

### 1️⃣ Clone the Repository
```sh
git clone https://github.com/YOUR_USERNAME/pga-live-scoring.git
cd pga-live-scoring
```

### 2️⃣ Install Dependencies
```sh
npm install
```

### 3️⃣ Start the Development Server
```sh
npm run dev
```

The site should now be running at `http://localhost:3000`.

## 🚀 Deployment Instructions
### Deploying on Vercel (Recommended)
1. **Go to [Vercel](https://vercel.com/) and sign in with GitHub**.
2. Click **"New Project"** → **"Import GitHub Repository"**.
3. Select your **pga-live-scoring** repo and click **"Deploy"**.
4. Once complete, you'll get a **live URL**!

### Deploying on Netlify (Alternative)
1. **Go to [Netlify](https://www.netlify.com/) and sign in with GitHub**.
2. Click **"New site from Git"**.
3. Select your **pga-live-scoring** repo and configure the build settings:
   - **Build Command:** `npm install && npm run build`
   - **Publish Directory:** `build`
4. Click **"Deploy Site"**.
5. Your live URL will be provided once deployment is complete!
